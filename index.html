PVC/VCM SD Mobilization Command Center

Upload the four source files to generate the report. All processing is done locally in your browser; no data is sent anywhere.

Before uploading: each file must contain the columns listed below its box. Column order is irrelevant and additional columns are ignored. Solid = required, dashed = optional (processing continues and the report states what could not be filled). After upload the chips turn green (found), amber (optional, not found) or red (required, not found).
Upload files 1 to 4; the report is generated automatically once all four are loaded. A file can be uploaded again at any time to refresh the figures. The optional TVC status file (EP and Pass / Fail result) powers the TVC Status tab and the TVC result in the Cards Tracker. The optional Last update file (the package-wise approvals table from the previous report) provides the Previous Data and Change figures.
